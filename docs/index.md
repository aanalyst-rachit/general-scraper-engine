# General Scraper Engine

A general-purpose Python web lead scraper for discovering and extracting structured business or professional leads from public web pages.

**Pipeline:** Discovery → Fetch → Parse → Relevance → Normalize → Quality Check → Deduplicate → Output

The project is a public-web lead scraper and does not provide login bypass, CAPTCHA bypass, private-page access, authentication bypass, or access-control circumvention.
